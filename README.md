# CampusPulse— College Event Management Website
Developed by SK Anisur Rahaman

FILES
- index.html: main website
- style.css: main styling, responsive layout and account screens
- portal.css: student/admin portal styling
- script.js: event features, registrations, and demo account interactions
- favicon.svg: site icon

RUN
Keep all five files in the same folder and open index.html in a modern browser.
An internet connection is recommended for Google Fonts and Unsplash gallery photos.

NEW ACCOUNT FEATURES
- Login and create-account tabs
- Name, email, password and confirmation validation
- Duplicate-email detection
- Password show/hide controls
- Local demo session and logout
- Personalized account welcome panel

IMPORTANT SECURITY LIMITATION
This is a front-end academic demo. Demo account details and passwords are stored in this browser and are not protected; never use a real or reused password or sensitive information. The login is not secure authentication and does not protect administrator sections. A real public website requires a backend, server-side password hashing, HTTPS, session management, and role-based access control. Registrations and accounts do not sync between devices.
