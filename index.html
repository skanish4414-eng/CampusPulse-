THE IDEA BEHIND IT

Made for the
makers & doers.

CampusPulse is a student-focused College Event Management Website created as an academic web-development project. It brings event discovery, registration, campus highlights and feedback into one responsive experience.

The project demonstrates how HTML structures content, CSS creates a consistent visual system, and JavaScript adds useful behaviour.
